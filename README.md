# toweringpluto.github.io

Personal portfolio website for Stephen Olaluwoye.
## Live

[toweringpluto.github.io](https://toweringpluto.github.io)

## About

A single-page portfolio built with static HTML, CSS, and vanilla JavaScript. Dark blue/purple theme with a two-column layout inspired by [brittanychiang.com](https://brittanychiang.com).

**Sections:** About · Experience · Projects · Education & Awards

**Features:**
- Sticky sidebar with scroll-spy navigation
- Responsive layout (mobile-first, collapses to single column)
- Accessible — semantic HTML, ARIA labels, keyboard navigable, reduced-motion support
- No frameworks, no build step — ships directly via GitHub Pages

## Tech

HTML · CSS · JavaScript · [Inter](https://fonts.google.com/specimen/Inter)

## Run locally

Open `index.html` in a browser, or serve it:

```bash
python -m http.server 8090
```

Then visit [localhost:8090](http://localhost:8090).
